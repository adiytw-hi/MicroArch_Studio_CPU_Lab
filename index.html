Assumptions, limitations & student checklist

Architecture: 16-bit signed registers, R0 hardwired to zero, eight registers (R0–R7), 64 word-addressed data-memory locations, program-memory PC in instruction indices. Fixed-width 16-bit wraparound. Immediate offsets are signed integers. Instruction encodings are symbolic, not actual machine-code bit patterns. ADD, ADDI, SUB, LOAD, STORE, BEQ, BNE, JMP, HALT are supported.
Timing: Sequential mode counts one instruction as one teaching cycle, not real hardware cycles. The optional five-stage pipeline is a teaching timing schedule that assumes no forwarding, no cache delays, and simple branch penalties. It is not a cycle-accurate out-of-order or speculative CPU. Memory reads/writes occur in word units; no I/O, interrupts, floating point, caches or exceptions beyond bounds checks.

Verify before teaching: compile the example, observe R1 = 12 and a later STORE/LOAD, scrub backward and forward, inspect branch behavior, and compare sequential results with the pipeline's timing visualization. Exported CSV contains the sequential execution trace. Nothing is uploaded or stored remotely.
